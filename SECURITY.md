# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | Yes       |
| older   | No — please upgrade |

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Use [GitHub Security Advisories](https://github.com/suleymancelikel/metro-bundle-visualizer/security/advisories/new) to report privately.

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

You will receive a response within 72 hours. If the vulnerability is confirmed, a fix will be released as a patch version and credited in the changelog (unless you prefer to remain anonymous).
